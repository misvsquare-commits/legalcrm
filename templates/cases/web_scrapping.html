  1. Fetch Data — extracts text from the HTML page and lists PDF links.
  2. Extract PDF text (direct URL) — downloads a PDF and shows selectable text (left card).
  3. After a fetch, tick PDFs and click Extract PDF text to read those files.
  4. Or tick PDFs and Import into case to save them as documents.
